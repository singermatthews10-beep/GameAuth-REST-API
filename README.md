# GameAuth REST API

A Java-based REST API project developed using Dropwizard and tested with Postman.

## Project Overview

This project demonstrates a client-server application using REST-style communication and HTTP Basic Authentication. The service was configured to accept authenticated requests and return different responses based on whether the user provided valid credentials.

## Features

- Java REST API development
- Dropwizard framework configuration
- HTTP Basic Authentication
- Authorized and unauthorized request handling
- Client-server communication
- API testing with Postman

## Technologies

- Java
- Dropwizard
- REST APIs
- HTTP Basic Authentication
- Postman
- Client-Server Architecture

## What I Learned

This project strengthened my understanding of REST APIs, authentication, and client-server communication. I also gained experience testing API endpoints with Postman and verifying how applications respond to valid and invalid authentication requests.
